## Why

`add-neurons-local-pdf-provenance` (Phase 1) mapped only the **1128 figure/table questions** — the ones whose `{file, page}` came for free from the figure-extraction manifest. The other ~3472 questions (pure text 詳解) had no page, so the「看原始詳解 PDF」button never showed for them. Owner wants coverage extended toward all 4600.

The figure-detector `reconcile/healthcheck/detect_figures.py` already resolves **every** born-digital question's page deterministically (`find_question_starts` + `offset_to_page` over the source PDF text) — it just only persisted pages for figure questions. So the bulk is a deterministic extraction, not an LLM task: a fleet of agents counting pages would be slower, costlier, and prone to off-by-one ×thousands. Deterministic resolution + a second independent signal (stem cross-check) is faster and verifiable-by-construction.

## What Changes

- **New committed source** `packages/content-neurons-tw/provenance/question-page-map.json` — `{questionId: {file, page}}` (0-based) for text questions, generated by the new deterministic resolver `reconcile/healthcheck/resolve_all_pages.py` (reuses the trusted detector primitives).
- **Two-signal validation in the resolver**: (1) 題號 anchor page (`find_question_starts`), gated by within-booklet **monotonicity**; (2) independent **stem cross-check** (search the corpus stem's distinctive token in the PDF, compare its page). Classify each: `verified` (both agree ±1, ship), `anchoronly` (stem absent in 詳解 text — unverifiable but kept), `disagree` (signals conflict — **excluded** → agent adjudication). **notext (scanned) booklets are excluded** entirely (unreliable text layer → OCR/agent residual).
- **Builder merges two sources**: `build-provenance-map.mjs` now reads the manifest (figure, bbox-precise — wins on overlap) **and** the text page map, emitting one combined 1-based public map.
- **Coverage**: 1128 → **3398 shippable** (1128 figure + 2270 text: 1920 double-verified + 350 anchor-only). Deferred to a follow-up agent pass: **80 disagree + 157 suspect + 996 unresolved** (scanned + pattern-misses). Unmapped questions keep hiding the button (graceful — already specced).
