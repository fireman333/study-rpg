## Why

今日處方箋 is the app's daily anchor, but it has two gaps the owner has decided to close together (2026-07-07 locked design, Fable+Codex blind panel → Opus synthesis → owner 拍板):

1. **No cross-device continuity.** All daily-quest state lives in device-local `prescription:v1:*` meta keys (spec-mandated local-only; the sole synced family is the NG-0717 imprint keepsake). Three questions corrected on the phone are invisible on the laptop; the same day can double-advance NG-0717 only by luck of the existing per-day idempotent keys never meeting. Owner confirmed this is now a product gap, not a feature.
2. **No post-completion depth.** T1 (the existing two lines) is deliberately small (≤12 questions). Players who finish it and still have momentum get nothing structured to channel it into — while the app's most valuable behaviors (extra corrections, synapse-forming expeditions) go un-nudged. Owner chose a **4-tier same-day ladder** with strictly anti-anxiety framing: T1 stays the only thing called 「完成」, higher tiers are invites, nothing accumulates across days.

## What Changes

- **4-tier ladder on 今日處方** (all numbers dogfood-tunable):
  - **T1 基礎處方** = the existing two lines, zero mechanical change (`completed:{date}` keeps driving NG-0717 / imprints), now grants **+10** conduction energy (replacing the never-implemented `min(20, R)` optional reward).
  - **T2 追加固化** = ~3 more corrections from the same frozen `wrongEligibleQuestionIds` snapshot's overflow (pool exhausted → frozen fallback chain: breadth pool → cram practice at a doubled target), **+15**.
  - **T3 形成連結** = ≥1 synapse formed/strengthened today (listening to `connectome.synapseFormed` / `connectome.synapseStrengthened`; often reached naturally while doing T1), **+20** + an ephemeral glow.
  - **T4 深度出征 (stretch)** = cumulative ~12 corrections AND ≥2 synapses today, **+25** + optional cosmetic pulse (no exclusive power). Σ ≤ 70 energy/day.
- **Tier = pure DERIVED** (`derivedTier = f(winnerPlan, UNION'd progress keys)`) — no stored tier field, no new merge type. Display uses `displayTier = max(derivedTier, highestClaimedTier)` (claim-floor) so the shown tier is same-day monotonic even when a divergent plan loses the cross-device merge.
- **Daily-quest state becomes a date-windowed synced table** under the existing `prescription:v1:` namespace (NO v2 migration): `plan:{date}` (earliest-createdAt-wins MIN-LWW via a new backfill post-pass), `wrong:` / `breadth:` / `cramRescue:` (owner-locked SYNC) / new `wire:{date}:{pairKey}` / new `tierClaim:{date}:{2|3|4}` (all write-once UNION, window today ±1 day), `completed:` / `reward:` (write-once UNION, full history — they drive NG-0717 maturation). `lightsOut:` / `localSeed` stay LOCAL.
- **Energy is NEVER a scalar LWW value**: every grant is gated by an idempotent write-once claim marker (`reward:{date}` for T1, `tierClaim:{date}:{tier}` for T2–T4) and delivered as a **flat write into the existing `maze:<familyId>:earned` MAX-merge counter**, granted to a plan-frozen deterministic family — so a cross-device double-claim collapses on merge instead of stacking, and a pulled claim never re-grants.
- **Reward delivery at tier crossing**: hooks at the `recordPrescriptionAnswer` tail, a new connectome synapse-event listener, and the cram record point; Dexie tx writes the claim only if absent, then post-commit flat grant + toast.
- **Anti-anxiety guardrails**: T1 is the only tier called 「完成」; the T2–T4 panel does not exist in the UI until T1 is done (progressive disclosure, mirroring the 考前救援 gate); tiers do NOT accumulate across days (no streak / weekly stats / collection / leaderboard / DMN axis); un-reached tiers use invite tone; the copy-guard test's banned tokens extend (未達成 / 落後 join the already-banned 還差 / 連續); objectives auto-shrink at plan generation with a frozen fallback chain so no「今天不可能達成」dead state exists.
- **Celebration-once**: the day-completion celebration plays only on the first-completing device; a device learning completion via sync renders the completed state silently.
- **BREAKING (sync surface):** R2 bundle `SCHEMA_VERSION` bumps **25 → 26** (single additive bump, reader-tolerant both directions; 25 was taken by the shipped pin-queue change). **ZERO Dexie bump, ZERO Worker change, ZERO new TableAdapter** — `isSyncedMetaKey` gains a prescription sub-key matcher single-sourced from `prescription.ts` (mirroring `IMPRINT_PREFIX`), and the only new merge machinery is the plan MIN-LWW post-pass in `backfill/`.

**Owner-locked product calls**: 4 tiers ✓; reading does NOT count toward any tier ✓; cramRescue SYNC ✓; forgiving pre-convergence crediting ✓; celebration-once (first-completing device) ✓. Energy amounts 10/15/20/25 are dogfood-tunable defaults.
