### 一週可讀性理由
- **big-subject 判定成立**：42 葉 = 組織學（25 葉全 full）×1.7 → 全 full 一週唸不完，**必 depth-tier**。修正後 full 葉 = **34**（原設計 36），比病理 36 full 葉略輕。
- **公衛「full」比病理/組織「full」短**：制度 / 分類 / 公式 / 理論組件 是 table-native，環境 / 職業 / 行政 / 促進 四區的 full **denser-per-column、shorter-per-leaf**。唯一例外是**生統(6)+流病(9)=15 葉概念散文**（CI/type I-II/bias vs confounding/設計 tradeoff 需散文），這 15 葉是全科主要密度來源、也是**考試核心不可降級**（見下方「不可降級清單」）。
- **region-size 上限採 Fable 的「<10 葉 / one-sitting」bound，非病理的 ≤5**：公衛 full 葉短，6–7 葉 full 區單一 sitting 唸得完；Fable review 明認「largest region 8 葉仍在 one-sitting 界內」，size 從未被列為問題（split 純為預算 + 內容型態）。
- 總長推估：34 full-leaf ≈ 組織學（25 葉全 full）×1.36，其中 15 葉散文 + 19 葉表格密集；+8 brief-leaf 以約半密度 ≈ +4 full-equivalent → 全冊約 **38 full-equivalent leaves ≈ 組織學 ×1.5**；公衛表格友善度高，考前救急一週可唸完。

## 考點筆記（per region 高頻主題 + 易混 X-vs-Y）

### R1 生物統計（full）
- **高頻**：CLT / 抽樣分布、type I vs type II error 定義、CI 解讀、t-test vs ANOVA 適用時機、相關 vs 迴歸（r vs β vs R²）
- **X-vs-Y**：母數 vs 無母數選擇、名目/順序/區間/比例尺度 → 對應可用統計量、中位數 vs 平均對極端值敏感度（Q89-type）、獨立 vs 互斥 vs 相依事件機率（Q83-type）

### R2 流行病學研究設計（full）
- **高頻**：四設計時序與可算指標（cohort→RR/發生率、case-control→OR only、RCT→隨機分派/盲性、ecological→群體層次）
- **【Fable 補】橫斷面研究**：cross-sectional 只能算盛行率（非發生率）、無時序 → 不能推因果；**橫斷面 vs cohort 時序辨析**（考選部高頻）
- **X-vs-Y**：prospective vs retrospective cohort、nested case-control、**隨機分派 vs 隨機抽樣**（Q91-type）、生態謬誤（ecological fallacy）

### R3 疾病測量、偏差、篩檢、監測與人口指標（full）
- **高頻**：發生率 vs 盛行率（慢病盛行率變動因子 Q84-type）、incidence density vs cumulative incidence、Se/Sp 固定而 PPV/NPV 隨盛行率變、偏差三分類、傳染病法定分類與監測通報
- **【Fable 補】標準化**：直接標準化 vs 間接標準化（SMR）、age-adjusted rate — 為何需要標準化（族群年齡結構不同）
- **【Fable 補】篩檢偏差**：lead-time bias（前導時間）/ length-time bias（病程長短）/ overdiagnosis — 為何篩檢「延長存活」可能是假象
- **【Fable 補】生命統計 / 人口指標**：平均餘命（life expectancy）、人口金字塔、扶養比、life table 基本讀法
- **X-vs-Y**：selection vs information bias、confounding vs effect modification、篩檢 cutoff 移動對 Se/Sp 的 trade-off

### R4 環境衛生（full）
- **高頻**：風險評估四步驟（危害鑑定 / 劑量反應 / 暴露評估 / 風險特徵）、危害評估敘述辨錯（Q94-type）、空污一次 vs 二次污染物、廢水三級處理順序（Q93）
- **X-vs-Y**：**PSI vs AQI**（見 §事實嚴謹 1）、primary vs secondary pollutant（如 O₃ 為二次）、BOD vs COD、水中 DO 與優養化

### R5 職業醫學（brief）
- **高頻**：PEL-TWA / STEL / 最高容許濃度定義、重金屬 → 標的器官（Pb / Hg / Cd / As）、人因工學工作檯高度（Q92）、游離 vs 非游離輻射、職業致癌物、塵肺症分型
- **brief 呈現**：以 **discriminator 表**為主 —（金屬 → 症狀/標的器官）、（粉塵 → 疾病：矽肺/煤肺/石綿肺）、（輻射 → 效應）、（PEL 三類定義）。精簡散文導言，**不刪表**

### R6 衛生行政、醫療體系與健保制度（full）
- **高頻**：健保支付制度誘因比較（論量 / 論病例 / 論人 / 總額，哪種較不誘導篩選輕症 Q99）、醫療財源、醫療市場失靈特性、醫院品質評估工具（PDCA / 指標）、長照 2.0
- **X-vs-Y**：論量計酬 vs 論病例計酬（Tw-DRGs）誘因方向、部分負擔的道德風險抑制、公醫制 vs 社會保險 vs 商業保險

### R7 醫事法規與醫學倫理（brief）
- **高頻**：醫師法外國學歷甄試（Q100）、醫師執業登記 / 繼續教育、知情同意四要件、醫療法 vs 醫師法規範主體
- **brief 呈現**：**要件-list 表** —（知情同意：告知/理解/自願/能力）、（醫師法 vs 醫療法：規範「人」vs「機構」）、（四原則：自主/不傷害/行善/正義）。精簡散文

### R8 健康促進、行為科學與預防醫學（full）
- **高頻**：三段五級 intervention → level 對應（天天 5 蔬果屬哪段哪級 Q98）、HBM 六組件（哪個不屬 HBM Q97）、TTM 五階段、渥太華憲章五策略、社區心理衛生層級（Q96）、健康識能、減害策略
- **X-vs-Y**：初段促進健康 vs 特殊保護、HBM vs TTM vs 社會認知理論組件、健康促進 vs 疾病預防、大眾傳播 vs 人際傳播（`interpersonal-and-mass-media-theories`，降溫但仍考）

## 事實嚴謹熱點（公共衛生學特有的 考選部-vs-國際教科書 分歧風險）

> **鐵律**：考選部答案鍵優先，OE/PubMed 只作補強不作推翻。公衛**大量台灣本土制度/法規**無國際教科書對應，一律以衛福部 / 健保署 / 勞動部 / 環境部官方定義為準。content session 逐區驗證。

1. **空氣品質指標 PSI → AQI**（R4 環境衛生）— 台灣環境部 2016 以 AQI 取代 PSI。舊題（如 104-1 Q95）以 PSI 門檻計分，新題以 AQI。講義**必須並陳兩者 + 轉換年份**，不可盲斷單一「正確」指標；答案取決於考題年份。
2. **職業暴露限值**（R5 職業醫學）— 台灣用勞動部「勞工作業場所容許暴露標準」PEL-TWA / PEL-STEL / 最高容許濃度，術語與數值均異於 ACGIH TLV-TWA/STEL/Ceiling。**以台灣勞安法為準，勿抄 ACGIH 值**。游離輻射劑量限值走台灣游離輻射防護法。**【Fable 補】職業病認定**用台灣「職業病診斷認定基準」，勿用一般教科書泛論。
3. **全民健保與醫療法規**（R6 + R7）— 健保支付（論量 / 論病例 / Tw-DRGs / 論人 / 總額）、部分負擔、醫療財源 100% 台灣制度，無國際對應 → 用衛福部 / 健保署官方定義。醫師法 / 醫療法條文（外國學歷甄試、執業規範）須用**現行版本**，不可用一般 medical ethics 泛論替代。長照 2.0 為台灣制度。
4. **行為改變理論組件**（R8）— 健康信念模式（HBM）六組件（自覺罹患性 / 嚴重性 / 利益 / 障礙 / 行動線索 / 自我效能）— 考選部常考「哪個不在架構中」，須確認**自我效能是否納入該題版本**（Rosenstock 1988 後才加入）；TTM 五階段、渥太華憲章五策略用**台灣公衛教科書 canonical 中譯**，勿自創譯名。
5. **三段五級**（R8）— 依 Leavell & Clark canonical 對應（初段=促進健康+特殊保護、次段=早期診斷早期治療、末段=限制殘障+復健）；考選部針對具體介入（篩檢=次段、衛教 / 疫苗歸屬、天天 5 蔬果）測 mapping，須**嚴守台灣教科書標準對應，勿憑直覺分級**。
6. **生統慣例與中文尺度名**（R1 + R3）— case-control 只能算 OR（不可報 RR）、Se/Sp 與 PPV/NPV 隨盛行率變、type I/II error 定義、測量尺度中文（名目 / 順序 / 區間 / 比例）— 用**台灣教科書 canonical 中文與慣例**，避免英文教科書直譯落差。
7. **【Fable 補】法定傳染病分類**（R3）— 須 pin **台灣現行第一~第五類**（傳染病防治法），含通報時限差異；勿用美國 CDC notifiable disease 分類或舊版類別。
