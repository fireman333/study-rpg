### 一週可讀性理由

藥理是 10 科講義之一，總長須維持「考前一週唸得完」。兩大低頻質量塊 = **抗生素（11 leaf = 全科 16%，但個別 bmax6 罕見）** 與 **精神科（5 leaf 中低頻）**。為 11 個罕考抗生素類寫完整教學散文 = 篇幅暴增、yield 幾乎為零；一張 class→機轉→prototype→signature toxicity→抗藥性對照表就涵蓋全部。精神科同理由 discriminator 表最有效——正是 BRIEF 交付的東西。把 **24%（16/67）leaf 放 brief tier** 讓藥理與其他科等比例，而高頻 51-leaf 核心（全 9 常青 + 全 b≥10 穩定）仍拿完整處理。

**長度槓桿 = 深度分層，不是區數**：區數 17（≈3.9 leaf/區，與組織 3.6 / 胚胎 3.5 密度一致）只是導覽粒度。若整週跑太長，第一批壓縮槓桿是 **(1) 把 `hdt-autonomic` 或 `hdt-psychiatric-neurodegen` 之外的邊際 FULL 收更緊、(2) 必要時將 `hdt-autonomic` 降 BRIEF**（Codex/Fable 都點名它是最低產 FULL 候選）——**不要**增加 brief 抗生素區（已最佳 table-collapse）。

## 考點筆記（per region 高頻主題 + 易混 X-vs-Y）

- **hdt-general-principles**：PK curve / clearance / half-life / loading-dose 計算、pH-partition（弱酸弱鹼 ion trapping）、clinical trial phase I–IV；agonist vs partial-agonist vs inverse-agonist、competitive vs noncompetitive 拮抗；**CYP inducer（rifampin / phenytoin / carbamazepine / Griseofulvin 經典題）vs inhibitor（azole / macrolide / grapefruit）**。
- **hdt-autonomic**：direct（bethanechol / pilocarpine）vs indirect（neostigmine / physostigmine / 有機磷）膽鹼致效；**physostigmine（過 BBB）vs neostigmine（不過）**；3 個 antimuscarinic leaf 合成一張「臨床用途 → 代表藥 → 副作用」表；depolarizing（succinylcholine）vs nondepolarizing（rocuronium）NMB；有機磷中毒 + PAM 復活。腎上腺素性：**α1/α2/β1/β2 選擇性表**、epinephrine reversal、dobutamine（β1）vs dopamine 劑量效應、clonidine/methyldopa（中樞 α2）、phenoxybenzamine（不可逆）vs phentolamine（可逆）；過敏性休克首選 = epinephrine（考選部題）。**⚠ β-受體拮抗劑 cross-reference block（Fable 修正 #2 必附）**：β1-selective（metoprolol/atenolol/bisoprolol）vs 非選擇性（propranolol）、ISA（pindolol/acebutolol）、適應症；心血管治療用途完整內文歸 `hdt-antihypertensives`，此處只放「β-blocker 屬腎上腺素性拮抗劑」的定位對照 + 指向 `hdt-antihypertensives` 的導引，避免學生的自主神經全圖缺一角。
- **hdt-antihypertensives**：利尿劑 site-of-action（loop / thiazide / K-sparing / CA-inhibitor）+ 電解質（低 K / 低 Na / 高尿酸 / 高鈣）；ACEI 咳嗽 / 血管性水腫 / 高 K；CCB dihydropyridine vs non-DHP；心血管 β-blocker（承 `hdt-autonomic` cross-ref）。**降壓首選藥 = 考選部 vs 國際 divergence 熱點**。

## 事實嚴謹熱點（藥理特有的考選部 vs 國際教科書分歧風險）

藥理是全講義**分歧密度最高**的科。content session 必須以**考選部答案為 canonical**，遇分歧要**標註（不要靜默「訂正」）**：

1. **藥物分類邊界**：考選部多依 Katzung / Lippincott。Vaughan-Williams 抗心律不整 class 指派（amiodarone / sotalol 多 class）、利尿劑次分類、抗憂鬱「世代」標籤、cephalosporin 世代涵蓋——逐一對**該屆答案 key** 核，不要假設用最新教科書。
2. **首選藥物（"首選"）題**：本 corpus 極多（樣本 Q54 生殖器疱疹首選、Q66 過敏性休克首選）。考選部首選可能落後現行國際 guideline（降壓首選、H. pylori regimen、特定 seizure-type AED、經驗性抗生素）。**跟 key 走**，同時註明與 2020s guideline 的差異。
3. **Terfenadine / astemizole 心毒機轉（樣本 Q69/Q70）**：正解機轉是 **IKr / hERG（K⁺ channel）阻斷 → QT 延長 → torsades**，**不是 Na channel**。Q70 stem 曾暗示「Na」= 教科書陷阱（錯 channel 當 distractor）。**務必拉實際考選部 key 與選項**；key 說 K⁺/hERG 就寫 K⁺/hERG。
4. **中文藥名 / INN 拼法 / 學名-vs-商品名**：台灣慣例（acetaminophen vs paracetamol、epinephrine vs adrenaline）；台灣考試特徵詞 **灰嬰症候群**（chloramphenicol，Q55）、**Griseofulvin CYP 交互**（Q52）——用 corpus 自己的措辭。
5. **毒理解毒劑配對（hdt-toxicology-antidotes，常青）**：部分解毒劑選擇有台灣可及性差異；解毒劑對照表須與考選部 key **完全一致**（methanol / ethylene glycol → fomepizole vs ethanol；cyanide 解毒劑選擇）。高風險，因 specific-antidotes 是常青必掃。
6. **抗腫瘤 target-drug 對應（標靶 / 免疫檢查點，recency-hot）**：快速演變領域；舊屆 key 可能反映已被取代的 target 指派——每個 mAb/TKI 錨定**該屆答案**，不用最新 label。
7. **爭議（#）/ 送分題**：藥理 leaf 帶 disputedExcluded（`pharmacokinetics-adme` 單 leaf 3 題）；content 應標出考選部**送分 / 訂正**之處，不要把爭議題當定論呈現。依 project 規則，所有 mechanism / 受體-vs-channel / 解剖位置 claim 走**考選部-primary + OpenEvidence 查證**再定稿（`/oe`）。
