### 一週可讀性理由
- 每個 full 區 **≤5 葉**（僅 renal-endocrine=6，Fable 認可邊際），對齊 組織學/胚胎學 已上線 full 區的 5 葉天花板 → 單一 sitting 不爆量。
- brief 的「key 必背 + discriminator table only」對病理天生高度表格化主題（壞死型/肺炎分型/COPD/貧血MCV/淋巴瘤/骨腫瘤/水泡病皆 X-vs-Y）是**換更省時的呈現，不是縮水**。
- 總長推估：36 full-leaf ≈ 組織學（25 葉全 full）×1.44，+29 brief-leaf 以約半密度 ≈ +14 full-equivalent → 全冊約 **50 full-equivalent leaves ≈ 組織學 ×2**；病理表格友善度高，考前救急一週可唸完。

### 調整槓桿（assemble 後校準）
1. **偏長 → 降級順位**：(1) `hdt-renal-endocrine`（6 葉、mean b8.8、GN pattern 亦可表格化）為第一 full→brief 降級候選；(2) 若 R7 呼吸已升 full 則退回 brief。
2. **加厚 → 升級候選**：`hdt-respiratory`（breadth 最均勻 b9–12、題量 80）為唯一實質 brief→full。Fable/Codex 建議若做調整，優先走 **R7 呼吸↔R10 腎內分泌對調**（肺癌分子分型+ILD pattern 值得散文；GN pattern 可表格化），代價總長 +~1 sitting。**現況維持 R7 brief / R10 full**（Fable：長度充裕時 R7 brief + 強 discriminator table 可接受）。

## 考點筆記（per region 高頻主題 + 易混 X-vs-Y）

### 總論塊

**R1 細胞傷害、發炎與組織修復**（full）
- 壞死 5 型 discriminator（凝固/液化/乾酪/脂肪/類纖維蛋白 → 對應器官病因）
- apoptosis vs necrosis（intrinsic/extrinsic/caspase）
- amyloid 分類 AA/AL/ATTR/透析 Aβ2M + Congo red 蘋果綠雙折射
- 急性發炎介質（histamine/PG/LT/C3a-C5a/bradykinin）
- 傷口癒合（labile/stable/permanent cell・keloid）
- **【Fable 補】營養不良性 (dystrophic) vs 轉移性 (metastatic) 鈣化**（血鈣正常 vs 高血鈣）
- **【Fable 補】細胞內堆積**：脂肪變性 (steatosis)・lipofuscin・含鐵血黃素 (hemosiderin)・血鐵沉積症 (hemochromatosis)

**R2 血液動力學障礙（栓塞・梗塞・休克）**（full・新獨立區）
- Virchow triad → 血栓形成三要素

- 紅（出血性）梗塞 vs 白（貧血性）梗塞 → 對應器官（肺/腸 vs 心/腎/脾）
- 休克分期（compensated → progressive → irreversible）與分型（hypovolemic/cardiogenic/septic/anaphylactic/neurogenic）
- 水腫（transudate vs exudate 概念在此起，肋膜於 R7 呼吸收尾）

**R3 免疫、感染與遺傳疾病**（full）

- **ANCA 血清學**：c-ANCA/PR3=GPA・p-ANCA/MPO=MPA/EGPA（易錯熱點，見 §事實嚴謹）

**R4 腫瘤學總論**（full）
- oncogene vs tumor-suppressor 逐一 gene 對照（RAS/MYC/HER2 vs Rb/p53/APC/BRCA/VHL/RET）

- 致癌物（黃麴→HCC・石棉→間皮瘤・苯→白血病）
- 副贅瘤症候群（paraneoplastic）

- 皮膚癌 BCC/SCC/melanoma（ABCDE/Breslow）
- 眼科（Fuchs/ROP/眼內黑色素瘤）

> **葉歸屬邊界註**：`peripheral-nerve-injury-repair` 之 zh 橫跨周邊神經 + 骨骼肌 + 感染性骨關節，跨神經/骨骼肌兩系統。依「以神經肌肉為主軸」歸入 R13 神經（使 R13=5 / R14=4 較均衡）；drafter 撰寫時骨關節感染部分可簡述並在 R14 交叉指涉。

## 事實嚴謹熱點（病理學特有的 考選部-vs-國際教科書 分歧風險）

> **鐵律**：考選部答案鍵優先，OE/PubMed 只作補強不作推翻。content session 逐區驗證，generic LLM 最常在下列處配錯。

1. **WHO 分類版本落差** — 淋巴瘤（HL/NHL 類別）、CNS 腫瘤（WHO 2021 分子整合診斷 vs 傳統組織學）、肺癌分子分型。**一律對齊考選部出題年代（classic Robbins 框架），勿套最新 WHO。**
2. **腎絲球疾病命名** — MPGN type I/II vs 新的 C3 glomerulopathy、RPGN 三型；用經典 Robbins 命名。
3. **細胞死亡** — 守經典壞死 5 型 + apoptosis；新型 regulated death（ferroptosis/pyroptosis/necroptosis）僅在考選部實際考過才寫。
4. **自免肝與血管炎抗體對應**（LLM 頭號配錯區，逐條查證）— AMA→PBC / ASMA・anti-LKM→AIH / p-ANCA→PSC；c-ANCA(PR3)=GPA / p-ANCA(MPO)=MPA・EGPA。
5. **致癌基因/抑癌基因 gene-tumor 精確配對** — Rb/p53/APC/VHL/RET/NF1-2/WT1/BRCA；LLM 常混 receptor vs channel、gene vs pathway，逐一驗。
6. **甲狀腺乳突癌核特徵**（Orphan-Annie eye/psammoma body）vs 濾泡癌（需 capsular/vascular invasion、FNA 不能診斷）— 精確描述。
7. **大腸癌分子路徑** — CIN（APC→KRAS→p53）vs MSI/MMR/Lynch，**基因順序勿倒**。
8. **台灣流病偏重**（考選部明顯偏本土，內容須鏡射）— HBV-HCC、EBV-NPC、檳榔-口腔癌、砷(烏腳病)-皮膚/膀胱癌、肝吸蟲-膽管癌、B 肝盛行。
9. **Amyloid 亞型**（AA/AL/ATTR/透析 Aβ2M）與染色（Congo red 蘋果綠雙折射）。
10. **grading/staging 慣例與 biomarker cutoff** 可能沿用舊版教科書 — 錨定考選部答案鍵而非最新指引。
