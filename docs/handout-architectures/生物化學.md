## 考點筆記 (per region 高頻主題 + 易混 X-vs-Y)

> 已併入 Fable keypointGaps 補的「機制＋臨床」高頻 hook（★ 標記 = Fable/Codex 新增、content session 必落地）。

- **R1 胺基酸/蛋白質**：等電點/pKa 計算、二/三/四級結構與變性、雙硫鍵、Hb 的 T↔R 異位（BPG / Bohr effect）vs Mb 雙曲線。★**collagen（Gly-X-Y 重複、proline/lysine 羥化需 vitamin C、壞血病 scurvy、OI / Ehlers-Danlos）**——蛋白質結構最常考的臨床 hook。
- **R2 酵素/維生素**：Km↑Vmax 不變 = competitive；uncompetitive vs noncompetitive 對 Km/Vmax 各自方向；每個 B 群維生素→哪個酵素反應（TPP/FAD/NAD/PLP/biotin/B12/folate）。★**脂溶性 ADEK 各自功能/缺乏**（A 視覺/retinoic acid、D 鈣、E 抗氧化、K γ-carboxylation 凝血）——leaf 有但原 keypoint 只寫水溶性。
- **R3 醣脂膜**（brief）：glycosidic α/β、GAG 種類、膜流動性、主動 vs 促進性運輸、膜蛋白拓樸（周邊 vs 嵌入 vs translocon）。
- **R4 醣代謝**：PFK-1 與 F2,6BP 雙向調控、RBC 無粒線體只走糖解、PPP 供 NADPH。★**肝醣儲積症**（von Gierke=G6Pase / Pompe=lysosomal / McArdle=muscle phosphorylase / Cori）。★**G6PD→NADPH→GSH→溶血（hemolysis）功能群**（glutathione 移入此區的機制理由）。
- **R5 TCA/oxphos**：不可逆步驟、解偶聯蛋白 / ionophore、⚠**P/O ratio 與每葡萄糖 ATP 數**（見事實嚴謹熱點 #1）。
- **R6 脂質**（brief）：各路徑速率限制酵素（ACC / HMG-CoA reductase / CPT-1）、MCAD 缺乏、酮體生成/利用組織 + 飢餓/DKA、脂蛋白 CM/VLDL/LDL/HDL 分類 + apo + LPL/LCAT/CETP。

- **R8 DNA**：Tm 與 GC%、pol III vs 真核 pol δ/ε、校對 3′→5′ exonuclease、修復機制配對（NER / MMR / BER / 光解酶）。★**修復缺陷臨床症候群：xeroderma pigmentosum (NER)、HNPCC/Lynch (MMR)**——把機制配對升級成臨床連結。

- **R10 轉譯/PTM/降解**：Shine-Dalgarno vs Kozak、起始 tRNA（fMet vs Met）、wobble 配對、抗生素抑制點、泛素-蛋白酶體標記。
- **R11 技術/藥物**（brief）：RFLP/PCR/Sanger/RNAi 用途、AZT/5-FU 機轉、reverse transcriptase / telomerase。
- **R12 訊息（一）**：GPCR→cAMP/PKA、PLC→IP3/DAG/Ca、核受體走 transcription、cGMP/NO。★**cholera toxin（Gs ADP-ribosylation 鎖 ON）/ pertussis toxin（Gi 失活）**——GPCR 招牌毒素考點。

## 事實嚴謹熱點 (生物化學 特有的 考選部-vs-國際教科書 分歧風險，content session 要盯)

> 全部走 **/oe（OpenEvidence）+ 考選部答案鍵雙軌驗證**；divergence-prone 者以考選部該 sitting 的答案鍵 convention 為準，不可統一套現代教科書值。

1. **⚠ 最重要 — P/O ratio 與每葡萄糖 ATP 產量**：舊答案鍵常用 P/O 3/2 → **38 ATP/glucose**；現代教科書（Lehninger 近版）用 2.5/1.5 → **30–32 ATP**。content session 必**逐 sitting 確認該題採哪套 convention**，不可統一套現代值。★**延伸（Fable）**：ATP yield 也受 shuttle 影響——**malate-aspartate shuttle**（NADH 全額）vs **glycerophosphate shuttle**（降為 FADH₂ 當量），content session 一併確認。
2. **維生素/輔酶命名**：niacin/nicotinic acid vs niacinamide、TPP vs thiamine pyrophosphate、pantothenate→CoA。考選部 keys 對「哪維生素→哪酵素/缺乏症」很精確，依台灣教科書（Harper / Lippincott 中譯）命名。
3. **酵素抑制動力學方向**：competitive / noncompetitive / uncompetitive / mixed 對 Km·Vmax 的方向用古典 Lehninger convention；mixed 與 noncompetitive 勿混。
4. **先天代謝異常↔酵素缺陷配對**：PKU=PAH、MMA=methylmalonyl-CoA mutase/B12、MCAD、maple syrup urine=BCKDH — clinical pairing 要對到考選部指定的確切酵素名。
5. **藥物/抗生素抑制步驟分類**：30S vs 50S、轉錄 vs 轉譯、AZT=RT 抑制、5-FU=thymidylate synthase — 分類 divergence-prone，依藥理教科書。
6. **原核 vs 真核 複製/轉錄/轉譯機器對應**：pol III vs pol δ/ε、單一 RNA pol vs I/II/III、70S vs 80S — 考選部愛考此對照，配對務必精確。
7. **★ 新增（Codex）— 訊息傳遞路徑/分子對應風險**（涵蓋 R12 hdt-signaling + R13 hdt-kinase，合計 12 leaf，原清單漏列）：G 蛋白亞型與效應對應（Gs→AC↑、Gi→AC↓、Gq→PLC-β）、第二傳訊者→下游激酶配對（cAMP→PKA、DAG→PKC、Ca²⁺-calmodulin）、cholera/pertussis toxin 作用亞型、insulin 受體屬 RTK 但下游走 PI3K-Akt（非典型 Ras-MAPK 主線）、caspase initiator vs executor。這些配對是 divergence-prone，須 /oe + 教科書雙軌對齊，勿憑泛用 LLM 知識（易把 receptor/second-messenger/kinase 對錯）。
