## 事實嚴謹熱點 (免疫學 特有的 考選部-vs-國際教科書 分歧風險，content session 要盯)

> 全部走 **/oe（OpenEvidence, PubMed-anchored）+ 考選部答案鍵雙軌驗證**；divergence-prone 者以考選部該 sitting 答案鍵為準，現代教科書與考選部矛盾時 **footnote 分歧、不靜默「訂正」答案鍵**（per project rule：答案鍵權威 = 考選部）。Fable fact spot-check 判所有 disease 分派/表型/藥物對映無誤，以下為需盯的 divergence 面。

1. **⚠ Gell-Coombs 過敏分型**：考選部維持 classic Type I–IV，**不可引入國際版 Type V**（stimulatory, Graves/myasthenia）——考選部把 Graves/MG 歸 **Type II**。核對疾病：**SLE & serum sickness = III；AIHA & Goodpasture = II**（Fable 判定正確，勿反）。
2. **Hyper-IgM 分類**：CD40L（X-linked, type 1, 最常見）vs CD40 vs AID/UNG（AR）；考選部考確切分子 + 遺傳模式，最易互換。
3. **MHC/HLA 胜肽 loading 細節**：確切成分（I：proteasome/TAP/tapasin；II：invariant chain/CLIP/HLA-DM）+ 胜肽長度；考選部愛考這種精確值。
4. **疫苗 live-attenuated vs inactivated 清單**：對齊台灣 CDC 疾管署接種時程用語；**BCG 是台灣常規、重考**（國際教科書淡化）。Rotavirus/OPV/MMR/varicella = live；核對現行台灣時程。
5. **補體調節子→病 + 終末補體→Neisseria**：C1-INH→hereditary angioedema、DAF/CD59→PNH、Factor H→aHUS——標準但細節密。
6. **Checkpoint-inhibitor drug→target 對映 + 機制部位**：nivolumab/pembrolizumab=PD-1、atezolizumab=PD-L1、ipilimumab=CTLA-4；**CTLA-4 作用於 priming vs PD-1 作用於 effector**——升溫現代熱點、藥名更迭快。
7. **CD4-subset master-TF/cytokine 配對**：須教科書精確（TH17 = **RORγt 非 RORα**、TH1 = T-bet）。
