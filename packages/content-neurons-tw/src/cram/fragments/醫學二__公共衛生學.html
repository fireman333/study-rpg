📐 公式卡 / 易混定義

統計檢定選擇總則比較「均值(連續)」→ t/ANOVA；比較「比例(類別)」→ chi-square/Fisher
Paired t-test vs Two-sample t-test同一組人前後測 → paired；兩組獨立不同人 → two-sample(independent)
Chi-square vs Fisher's exact2×2 有任一格期望值 <5(小樣本) → Fisher；期望值夠大 → chi-square
McNemar test類別變項的「配對/前後測」設計（≠ 獨立樣本 2×2 用 Fisher/chi-square）
≥3 組獨立樣本比均值ANOVA（≠ 三組不能用 t-test 或 Z-test）
兩連續變項相關/預測(兩者皆連續)linear regression / Pearson；反應變項二分類 → logistic regression
Spearman correlation至少一變項為有序(ordinal，如年齡分級/薪資高中低)、免常態假設
Type I error (α)H0 實際為真卻推翻它（偽陽性；顯著水準）
Type II error (β)H0 實際為假卻沒推翻它；β = 1 − power
Power(檢定力)= 1 − β；H0 為假時正確拒絕的機率。↑樣本數 / ↑α / ↑effect size 皆提升 power
樣本數估計方向↑SD → 樣本數↑；↑effect size / ↑α / ↓power(需求) → 樣本數↓
Sensitivity(敏感度)有病者中測陽性的機率（有病→測得出）
Specificity(特異度)無病者中測陰性的機率（沒病→測沒病）
PPV / NPV陽性者中真有病 / 陰性者中真沒病；PPV 受盛行率影響（盛行率↓ → PPV↓、偽陽性比例↑）
Cut-off 移動放寬標準 → 敏感度↑、特異度↓、偽陽性↑（Se 與 Sp 無法同時最大化）
相關係數 r vs 決定係數 R²R² = r²；「可被解釋的變異比例」用 R²（r=0.4 → 只解釋 16% 非 40%）
Pearson r 性質介於 −1~1；r 與迴歸斜率 b 同號；r 顯著≠因果、相關≠因果
比較不同單位變異大小變異係數 CV = SD/mean（消除單位；SD/variance 受單位影響不能比）
Odds ratio 判有無關聯看 OR 95% CI 是否含 1（含 1 = 無關聯）；≠ 與 0 比較

Bias 型別定義 / 一句鑑別經典例
生態謬誤 (ecological fallacy)用群體層級相關硬推個體因果各國乳癌率↔高血脂盛行率
選樣偏差 (selection bias)研究對象選取階段就偏健康工人效應 (healthy worker effect)
訊息偏差 (information bias)資料測量/收集錯誤造成測量誤差、錯誤分組
干擾 (confounding)第三變項同時與暴露和疾病相關加入 logistic 迴歸「調整」處理

研究/檢定概念特徵一句鑑別
生態學研究 (ecological study)以族群為單位、僅總和資料無個人暴露；最難控干擾
病例對照 (case-control)回溯、只能算 OR、算不出發生率/RR；單向
巢式病例對照 (nested case-control)雙向研究法（前瞻追蹤 + 回溯暴露）
新藥上市前評療效隨機分派試驗 RCT (Phase 3)；廣告缺陷=沒對照組
交互作用 (interaction) vs 干擾「關聯隨X狀態而變」= 效應修飾查 interaction；調整只能控干擾
平行檢定 (parallel) vs 系列檢定 (series)parallel(任一陽即陽)→淨敏感度↑特異度↓；series(皆陽才陽)→特異度↑
中央極限定理樣本平均值分布趨常態(非 Poisson)；SE 取決於母體SD與樣本大小
