🧬 骨架（傳導路徑）

視覺傳導路徑：視神經 → 視交叉 → 視徑 optic tract → 外側膝狀體 LGB → 皮質（上丘＝反射旁路，不在主路）
牽張反射傳入纖維：肌梭 → Ia（大髓鞘、單突觸）；高基氏肌腱器 → Ib（下運動神經元損傷 → 反射消失）
皮質脊髓徑下行：內囊後肢 → 中腦基底腳（大腦腳）→ 橋腦基部 → 延腦錐體（側徑在此交叉）
