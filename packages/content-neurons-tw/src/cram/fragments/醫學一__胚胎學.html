🎯 高頻考古

  • 嚼肌（masseter） → 第一咽弓（CN V）；第一弓也給 malleus/incus + 上下頷，第二弓（CN VII）→ stapes + 表情肌 反覆考
  • 動脈導管（左第六主動脈弓衍生） → 出生後閉鎖成 ligamentum arteriosum；左喉返神經繞其折返 反覆考
  • 輸尿管芽（ureteric bud） → 集尿系統（輸尿管/腎盂/腎盞/集尿管）；後腎中胚層 → 鮑氏囊/近曲小管/腎絲球 反覆考
  • Sertoli cell 分泌 MIS/AMH → 使副中腎管（Müllerian duct）退化；睪丸決定因子（SRY/TDF）在 Y 染色體 反覆考
  • 脊索（notochord） → 髓核（nucleus pulposus）；生骨節（sclerotome）→ 椎體；軸旁中胚層 → 體節 常考

🔢 咽弓衍生物速查（反覆考爆）

第一咽弓 muscle / 神經咀嚼肌（含 masseter）；三叉神經 CN V
第二咽弓 muscle / 神經表情肌；顏面神經 CN VII（第三=舌咽 CN IX，第四/六=迷走/副神經）
聽小骨砧骨+槌骨=第一咽弓；鐙骨=第二咽弓
主動脈弓／左總頸動脈／動脈導管主動脈弓=第四；左總頸=第三；動脈導管+肺動脈=左側第六（升主動脈非咽弓，來自動脈幹）

🔢 咽囊 / 咽溝 / 耳鼓膜歸屬

第一咽囊(內胚層)鼓室 + 耳咽管；呼吸原基起源於第四咽囊尾端前腸腹側
外耳道 / 鼓膜外耳道=第一咽溝(外胚層)；鼓膜=第一咽溝外胚層+第一咽囊內胚層+咽弓間葉三胚層（神經外胚層不參與）
甲狀腺 C-cell / 脫離點濾泡旁細胞來自第四咽囊(後鰓體)；甲狀腺憩室脫離處=盲孔（非門齒窩）

🔢 三胚層 / 神經嵴 歸屬

外胚層(surface)衍生表皮、汗腺分泌部、皮脂腺、毛髮、指甲（豎毛肌=中胚層，非外胚層）
神經嵴 neural crest黑色素細胞、交感節後神經元、腎上腺髓質嗜鉻細胞、角膜內皮（甲狀腺濾泡細胞=內胚層，非神經嵴）
骨骼系統來源中胚層 + 神經嵴（頭骨外骨骼=中胚層，顱骨=神經嵴間充質）
角膜三層外皮=體表外胚層；間質=中胚層；內皮=神經嵴（角膜由水晶體泡誘導，非視網膜）
